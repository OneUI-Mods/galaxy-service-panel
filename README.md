# Galaxy Service Panel

Samsungの `*#0011#` から開くService Modeを、読みやすいMaterial 3の画面に整えるVectorモジュールです。

- SIM選択をカード表示にし、診断値をSIM・接続、LTE、NRの区切りで表示。
- 複数の測定値を揃えて表示。画面幅と文字サイズに合わせて折り返し。
- 「原文」タブと長押しで元の文字列・行番号を確認。
- 純正の診断値の更新、メニュー操作、タップ先の対応を維持。
- ON/OFFと文字サイズ調整。OFFにすると純正のビューとActionBarを復元。
- 日本語・英語、OSのアプリ別言語設定、ライト・ダークテーマ。
- 検証用の実機情報を使わないプレビューと、検索できるコンポーネント別ライセンス表示。

モデム設定、周波数、SIM設定、純正の更新間隔を変更する機能ではありません。診断データの送信や保存は行いません。コピーは利用者が長押しから明示的に操作した場合のみです。

## 対応環境

Android 17 / One UI 9、Galaxy S26 Ultra SM-S948QのServiceMode構造を調査して実装しています。Android 16は別の互換プロファイルを準備していますが、今回版の実機確認は未実施です。対象は `com.sec.android.RilServiceModeApp` の `0011` 画面だけです。構造が異なる場合は純正表示を維持します。

libxposed API 102対応のVectorが必要です。モジュールの表示設定にrootは必要ありませんが、フレームワークの導入にはroot環境が必要です。システムAPKは書き換えません。

## 導入

署名済みrelease APKをインストールし、Vectorでモジュールと推奨対象「Service mode RIL」を有効にします。Samsungの電話キーパッドで `*#0011#` を入力します。

Service Modeは電話機能と同じプロセスで動きます。初回のフック読み込みにはそのプロセスがモジュールを読み込める状態になる必要があります。アプリから電話・SystemUI・端末を自動で再起動する処理は入れていません。

アプリの「表示」タブでON/OFFと文字サイズ、「プレビュー」でサンプル、「情報」で対応環境と保護状態を確認できます。エラー時は純正へ戻し、保護を解除するまでは整形を再試行しません。
