# Galaxy Service Panel 0.1.0 — Service Modeを読みやすく

Samsungの電話で `*#0011#` から開くService Modeを、Material 3の画面へ整える実験版です。SIM選択をカードにし、接続情報とLTE・NRの測定値を区切って表示します。文字サイズを調整でき、「原文」タブと長押しから元の表示内容も確認できます。

診断値の更新や純正メニューは維持します。表示設定をOFFにすると純正表示へ戻ります。日本語・英語、ダークテーマ、サンプルプレビュー、コンポーネント別ライセンス表示に対応します。

Android 17 / One UI 9のGalaxy S26 Ultra向け。libxposed API 102対応のVectorが必要です。Android 16の実機動作は未確認で、Service Modeの版や機種によっては純正表示を維持します。

署名済みrelease APKをインストールし、Vectorでモジュールと推奨対象「Service mode RIL」を有効にしてください。初回は電話プロセスへモジュールを読み込む必要があります。アプリは電話や端末を自動で再起動しません。モデム設定、回線設定、純正の更新間隔は変更せず、診断値の送信や保存も行いません。
